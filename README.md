# 阿晔 / QURIOUS 个人网站

暗夜电影感个人主页。直接打开 `index.html` 或用任意静态服务预览；线上部署走 GitHub Pages（main 分支根目录）。

- `index.html` — 主站：Hero → 认识我 → 代表作 → 我的AI小站 → 页脚
- `ai-hub.html` — AI 小站：教程区 + 资源区
- `site.css` — 全部样式（深黑底 / 琥珀金 / 衬线标题 / 胶片颗粒）
- `site.js` — 渲染与交互（视差、移动端菜单、复制微信号）
- `content.js` — **唯一数据源**：姓名、定位、社媒账号、代表作、教程、资源都改这里
- `demos/` — 设计提案存档（A 暗夜[已采用] / B 画廊 / C 前卫）
- `assets/` — 照片与生成素材，`source/` 为原始大图
- `docs/`、`qa/`、`scripts/`、`source-reference/` — 旧版（V1 暖纸风）的资料与 QA，仅留档

V1 旧站源码另存于 `source-reference/`，未做修改。
