# 参考图计划与视觉锁定

## 状态

本环境没有可用的参考图生成工具。用户要求先完成可替换内容的网页，因此本项目采用“文字视觉基线”模式：不生成或伪造参考图，后续按 `content-style-brief.md` 的色彩、排版和版式实现。视觉核验状态为 `not verified against reference images`，但会进行浏览器渲染检查。

## 全站风格指纹

- Wordmark：小顾九. / XIAO GUJIU；不生成或仿造 logo。
- 色板：暖白 #F6F2EA、墨黑 #1D1C1A、灰 #716E68、深青 #275E67、陶土橙 #D96845。
- 字体角色：衬线 display；无衬线 body、nav 与标签。
- Chrome：顶部固定导航，窄屏折叠菜单；按钮为直角轻圆角，细边框与低对比纸纹。
- 共享材质：仅使用代码生成的极轻纸纹与网格，无 section 专属图片素材。
- 禁止项：渐变文字、炫光球、假仪表盘、虚构数据、虚构品牌、把真实账号或资料烘焙成图片。

## 审查结论

- 视觉意义：通过文字检查；每页均有单一用途和明确阅读路径。
- 一致性：通过；统一色板、字体角色、导航和按钮系统。
- 节奏：通过；主页偏丰富，其余页面在资料型与内容型之间交替。
- 可实施性：通过；全部先以可编辑代码呈现，真实照片和项目媒体不会被伪造。
- 参考图状态：not verified；用户后续提供头像、项目截图或喜欢的页面截图后，应重新锁定相关页面的参考图。
