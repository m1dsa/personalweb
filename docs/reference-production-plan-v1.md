## 1. 全站视觉指纹

- 视觉世界：暖米白编辑杂志主世界，穿插一次深蓝全息章节；整体是个人创作者档案，而不是通用 AI 产品站。
- 概念主线：`Archive / Dossier`——把人物、平台数据、代表作和摄影作品组织成可浏览的个人档案。
- 第二阅读细节：全站只使用一次窄竖向编辑注释轨，放在“工作之外”板块，用于加强摄影观看节奏。
- 主色：纸张 `#F4F0E8`、主文字 `#191817`、珊瑚橙 `#FF744C`、辅助灰 `#756F66`、深纸色 `#EBE4D8`、柔和青绿 `#B8D5CC`。
- 全息章节：深蓝 `#06286F`、深层阴影 `#03183A`、全息青 `#24CFFF`、高亮蓝 `#0F70E8`；珊瑚橙只保留为极少量行动提示。
- 字体：高对比编辑衬线体负责超大英文或中文标题；精炼 grotesk 无衬线负责正文和按钮；窄体无衬线负责导航、编号与英文小标签。
- 全局框架：顶部细线导航；左侧 `阿晔 / QURIOUS` 字标；矩形细边按钮；0—12px 小圆角；不用厚阴影、玻璃卡堆或蓝紫 AI 渐变。
- 材质：细点阵、纸张微颗粒、发丝级网格、橙色网点/粒子；摄影保持真实，只做轻量统一调色。
- 图像规则：真实人物照片、三张摄影作品和 X 原封面均为来源素材；不得生成替代内容或改写其主体。
- 动效暗示：轻微视差与粒子漂移；局部扫描显现；摄影画廊缓慢错层；联系区文字展开。静态图中只用层级和轨迹暗示，不堆动效图标。
- 密度节奏：首屏 rich → 全息区 rich → 代表作 medium → 摄影 calm-rich → 联系区 calm；AI 小站 medium。
- 黑名单：随机球体、无意义工程线、假 KPI、虚构品牌、重复 bento、渐变大字、过量卡片、烘焙会议背景文字、虚构社媒数字。

## 3. Section Render Contracts

### 01 首屏：名字与人物视觉

- 三秒信息：这是阿晔 / Qurious，一位 AI 实践者与内容创作者。
- 个人证据：用户提供的金发、白西装、黑西裤真实人物照片。
- 作者性动作：人物从真实照片向珊瑚橙网点粒子逐渐解构，巨型字标跨越分栏线但不遮挡面部。
- 第一焦点：右侧完整人物；第二焦点：`阿晔 / QURIOUS`；第三焦点：身份与格言。
- 阅读路径：人物 → 名字 → 身份与格言 → 右上导航。
- 代码安全区：左侧 40% 与顶部导航；人物头部和身体周围为闭合禁入区。
- 可见文案：只使用用户最终确认的首屏文案，不显示真实姓名或已删除的中文说明句。
- 留白职责：左侧为主文案呼吸区；人物右缘为粒子和响应式裁切跑道。
- 响应式：手机先文字后人物；人物头部、白西装与黑西裤必须完整可辨。

### 02 认识我与社媒数据

- 三秒信息：阿晔以多个平台持续创作，并以真实数字建立信任。
- 个人证据：David 式大头短身比例，但造型明确为金发、白西装、白内搭、黑西裤的阿晔卡通角色；只展示已核实数据。
- 作者性动作：扫描线从实体上半身过渡为全息下半身，数据行像空间标注一样与人物保持视觉关联。
- 第一焦点：左侧全息小人；第二焦点：右侧平台数据；第三焦点：`认识我 / WHERE I CREATE`。
- 阅读路径：角色 → 已核实数据 → 平台入口。
- 语义图形：连接线只表示“角色对应的平台资料”，不画无意义技术网络。
- 数据边界：平台顺序固定为 X → 小红书 → 抖音 → 哔哩哔哩 → 视频号；只显示已确认的 X `672` 与哔哩哔哩 `1,128`，小红书、抖音、视频号使用 `— / SOON`；视频号暂显示 `待补主页`；不得把 `1,800` 写成全平台总数，不虚构其他平台数字。
- 禁入区：任何线、文字、粒子不得进入人物面部、服装识别区和数据数字矩形。
- 响应式：手机角色置顶、数据置下；降低粒子和透视网格密度。

### 03 代表作与 AI 小站入口

- 三秒信息：左侧是可长期更新的 AI 小站，右侧是一篇已经取得真实互动的代表作。
- 个人证据：X 原文章封面、原题与公开互动数据；AI 小站只显示已确认的“教程区 / 资源区”。
- 作者性动作：像把一份档案向两侧展开，左侧是长期内容索引，右侧是被橙色装订线固定的代表作证据。
- 第一焦点：X 原封面；第二焦点：AI 小站入口；第三焦点：互动数据。
- 阅读路径：代表作封面 → 标题与数据 → AI 小站入口。
- 独立媒体：X 封面保持完整 2:1 比例，不与 AI 小站界面共享阴影或遮挡。
- 代码安全区：标题、数据、按钮均在纸张区，不烘进封面。
- 响应式：手机先 AI 小站、后代表作；封面不可裁掉主要文字与两个人物。

### 04 工作之外的我

- 三秒信息：专业工作之外，阿晔通过摄影观察日常。
- 个人证据：三张用户摄影作品原图。
- 作者性动作：花朵主图形成视觉停顿，秋叶与脚步照片像下一段胶片被轻微推入；窄竖向注释轨只在本屏出现一次。
- 第一焦点：花朵主图；第二焦点：秋叶；第三焦点：脚步照片。
- 阅读路径：标题 → 花朵 → 秋叶 → 脚步。
- 文案边界：只显示 `工作之外的我 / OUTSIDE WORK`，不添加标题、地点、年份或故事。
- 重叠：图片边框可轻微错层，但三个独立摄影主体不得互相遮挡。
- 响应式：手机一张完整主图加横向副图组，主要花瓣、秋叶天空和两双鞋都必须保留。

- 第一焦点：`COFFEE CHAT`；第二焦点：联系按钮；第三焦点：AI 群价格。

### 06 AI 小站独立页

- 三秒信息：这是阿晔长期整理 AI 教程与资源的独立入口。
- 个人证据：已确认的教程区、资源区和飞书正文链接工作方式。
- 作者性动作：把内容目录设计成编辑档案索引；教程区是浅色展开页，资源区是深色插页，形成明确但统一的两类内容。
- 第一焦点：`AI 小站`；第二焦点：教程区；第三焦点：资源区。
- 阅读路径：站名 → 教程区 → 资源区 → 返回个人主页。
- 内容边界：不把“待复核”的教程名称当作正式内容；卡片正文使用抽象占位条，不虚构数量、更新时间或下载量。
- 代码安全区：所有标题、筛选、按钮和未来动态数据保持独立可编辑。
- 响应式：手机先站名与返回入口，再按教程、资源顺序纵向排列。
