## 2. 四方向复核

### 视觉含义

每张图都有单一主任务：自我介绍、社媒证据、代表作、生活摄影、联系转化、AI 内容入口。装饰线、粒子和全息效果都服务于阅读或身份表达，没有把页面做成通用 AI 产品站。

### 全组一致性

六张图共享暖纸色、近黑、珊瑚橙、细线导航、编辑衬线标题和窄体英文标签；深蓝全息只在“认识我”章节出现一次，形成有意的情绪转折。`阿晔 / QURIOUS`、人物造型与内容边界保持一致。

### 避免单调

首屏为人物双栏，认识我为全息人物与数据，代表作为档案双焦点，摄影为图像画廊，联系页为巨型文字行动区，AI 小站为浅/深目录索引。不同板块没有复用同一套卡片骨架。

### 可复现与可落地

提示词、输入素材和每个板块的内容边界已记录；图片均为统一 `1672 × 941` 横向画幅。所有正文、数据和按钮都可在网页中作为可编辑内容实现，不需要把整张图直接当网页背景。
